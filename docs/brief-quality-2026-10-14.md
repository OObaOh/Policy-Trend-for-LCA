## 실제 실행·검증 범위

- 키 없이 실제 공식 HTML 재조회 및 회귀 사례 재추출 수행. 55건의 자료 ID·원문 URL·기존 편집 보고서 보존. 갱신된 자동 발췌는 회귀 사례 1건.
- `python -m pytest -q`: 41개 오프라인 테스트 통과. 실제 DOM 잡음 제거, 문단 인용, 제목만으로 연구 질문을 생성하지 않는 조건, 기존 보고서 보존 및 실패 재시도 포함.
- Chromium에서 화면 회귀 4개 통과. 핵심 사항의 잡음 제외, 원문 문단 이동, 가설/템플릿 분리, 아카이브 카드의 발췌 표시, 기존 보고서 표시, 빈 항목 및 HTML 문자열의 안전 표시 확인. 로컬의 Playwright 기본 브라우저 다운로드가 HTML을 반환하여 설치되지 않아, npm 배포 Chromium 실행파일로 검증. CI는 표준 Playwright 설치 경로 사용.
- 외부 AI 실호출은 수행하지 않음. API 키가 없으므로 한국어 심층 분석의 실제 출력 품질·호출 성공률·비용을 검증했다고 주장하지 않음.
- AI 경로는 모의 응답으로 검증. 정상 응답의 채택, 없는 문단·근거 없는 수치·영어 응답·일반 연구 질문·잘못된 자료형의 거부, 응답 거부·토큰 초과·429 오류 시 기존 보고서 보존 확인.
- 인용 ID·수치 검사는 필요한 최소 방어선이다. 인용이 존재해도 해석 오류·과도한 일반화·단위 왜곡은 가능하므로 AI 결과는 `ai_preliminary`이며 의미 검토가 필요하다.
- HTML 기반 규칙은 모든 기관·언어의 논리 구조를 해석하지 못한다. 분류 실패 시 빈 항목을 유지하며 일반론으로 채우지 않는다. 첨부 문서, 유료 전문, 법률 교차검증 및 선행연구 조사는 이번 자동화 범위 밖이다.
